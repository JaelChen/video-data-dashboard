# 界面美化

这套看板的界面是边做边调出来的：先做出能用的版本，再参考一张 Dribbble 上喜欢的设计稿，把它的配色、字体和卡片做法提炼成一套规范，最后统一套到所有页面上。下面是这套规范，以及让 AI 帮你改界面的方法。

## 设计原则

- **少即是多。** 白底，灰色卡片里嵌白色面板，只用一种强调色（墨绿）。数据本身才是主角。
- **一张图只回答一个问题。** 每个卡片的标题写成问题或结论，比如「观众在哪一秒离开」，而不是写「留存图」。
- **颜色要有含义。** 平台颜色在所有图里保持一致；绿色只表示「比平时好」，红橙色只表示「比平时差」，不拿来做装饰。
- **相对值比绝对值更有用。** 小账号的 800 播放和大账号的 8 万播放没法直接比，所以每个指标旁边都标出「比你平时高 / 低多少」。

## 设计规范

全部写成 CSS 变量，放在 `dashboard/index.html` 开头的 `:root` 里，改这一处就能整体换风格。

| 用途 | 变量 | 值 |
|---|---|---|
| 页面底色 | `--bg` | `#ffffff` |
| 卡片（外层） | `--card` | `#f4f5f3` 浅灰 |
| 面板（卡片里的白块） | `--inner` | `#ffffff` |
| 分隔线、网格线 | `--line` | `#e8eae6` |
| 正文 / 次要 / 更淡 | `--fg` / `--muted` / `--dim` | `#131713` / `#4f564f` / `#8a908a` |
| 深色强调（导航选中） | `--ink` | `#16211a` |
| 强调色（好） | `--green`、`--mint-bg` | `#2f7d4f`，浅底 `#d9f5de` |
| 警示色（差） | `--warn` | `#d2593f` |
| 圆角 | `--radius` / `--radius-in` | 外层 22px，内层 16px |
| 平台色 | `--p-xhs` / `--p-douyin` / `--p-channels` | `#eb6834` / `#2a78d6` / `#1baf7a` |

字体用 Plus Jakarta Sans（Google Fonts），中文回退到苹方或微软雅黑。标题字重 600，字距稍微收紧（`letter-spacing: -0.02em`）。

几个反复用到的组件：

- **卡片套面板**：外层是浅灰卡片，`padding` 只有 8px，里面放白色面板。比给卡片加阴影更干净，层次也清楚。
- **胶囊**：导航项、标签、涨跌标记都用全圆角（`border-radius: 99px`）。导航选中时是深墨绿底配白字。
- **涨跌标记**：比平时高 15% 以上显示绿色「▲ +xx%」，低于平时 15% 以上显示红橙色「▼ -xx%」，差距在 15% 以内显示灰色「持平」。
- **图表**：ECharts 用 SVG 渲染；去掉坐标轴线，只保留很淡的横向网格线；图例用小圆点；图里的颜色全部从 CSS 变量读取。

## 踩过的坑

- **不要加淡入动画。** 浏览器在后台标签页里会暂停动画，页面会一直停在透明状态，看起来就是一片空白。
- **手机端**：侧边栏在窄屏下改成顶部横排；表格外面包一层可以横向滚动的容器，不要让整个页面左右晃。
- **数据异常要拦住。** 平台偶尔会返回不合理的数据（比如封面点击率 136%）。在入库时就把这类值置为空，比在界面上显示一个离谱的数字强。

## 用 AI 改界面的方法

1. **找参考。** 在 Dribbble 或 Behance 上找一张你喜欢的 dashboard 设计，截图或者复制链接。
2. **只要风格，不要布局。** 对 AI 说：「参考这张图的配色、字体、圆角和卡片层次，改 `dashboard/index.html` 里的 `:root` 变量和组件样式。不要改图表逻辑和数据结构。」
3. **先定规范，再铺开。** 让 AI 先把颜色、字体、圆角写成 CSS 变量；你在浏览器里看过、觉得满意了，再让它统一应用到所有组件上。
4. **在真实数据上检查。** 用 `./preview.sh` 打开，四个视图（总览、作品对比、单条诊断、内容规律）都点一遍，再把窗口拉窄看看手机效果。
5. **一次只改一件事。** 比如「卡片圆角再大一点」「涨跌标记换成胶囊」。小步迭代，比一次提一大堆要求更容易改出满意的效果。

想换成别的风格，基本只需要改 `:root` 里的那十几个变量。
